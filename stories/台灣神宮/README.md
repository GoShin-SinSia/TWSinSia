# 台灣神宮聊天室劇情

每階段一份 CSV，依序讀取 `stories/台灣神宮/台灣神宮1.csv`、`台灣神宮2.csv` 等。路徑使用「台灣神宮」，不是介面顯示的「臺灣神宮」。第二階段不存在時顯示「下一階段尚未開放」，保留第一階段進度；補檔後可再次按「繼續劇情」。

欄位：`編號,類型,訊息A,訊息B,秒數,紅字`。編號在同一檔內不得重複，依 CSV 列順序播放。已發布後應避免重排正在使用的階段；測試編修後可重置劇情。

- `npc`：A 為日文，B 為中文，翻譯鍵切換兩者。秒數是輸入動畫時間，空白預設 7 秒，0 表示沒有輸入動畫。送出前固定先等待 3 秒。
- `os`：下方內心對話框，點擊繼續，不加入聊天紀錄。
- `player`：單一選項，點擊才送出玩家訊息。
- `hint`：階段末任務提示。確認已讀後啟用該階段任務，等待任務打卡完成才顯示「已完成任務目標。」與「繼續劇情」。目前未接照片上傳。

首次進入行囊聊天室物件後 3 秒送出第一則 NPC 訊息（此則忽略 CSV 秒數），同時讓聯絡人出現在列表。舊版空聊天室測試資料會在首次開啟時升級。

每段連續 NPC 訊息結束後自動顯示「確認已讀」，不需要 CSV 額外列。確認前不顯示 OS、回覆或 hint。離開聊天室後依時間繼續送達，到確認點停住；關閉網站時不執行背景服務，下次登入依儲存的時間補齊該段訊息。OS、回覆與任務狀態均保存進度。

播放器在 `shrine-chat-player.js`，共用等待時間為 `CHAT_WAIT_MS`、預設輸入秒數為 `CHAT_DEFAULT_TYPING_SECONDS`。關卡開放條件與個人頁變化未納入 CSV。

選填「紅字」欄位：該列訊息中完全相同的字串會標紅，所有出現位置皆套用。A/B 各自比對，翻譯切換不影響規則。適用 NPC 訊息、玩家選項與送出泡泡、OS、hint；空白不標色。內容以純文字處理，不支援 HTML 或正規表示式。

任務由 `CHAT_STAGE_TASKS` 設定，每個有 hint 的階段須配置完成條件，未配置時不自動跳過。第一階段目標「狛犬」暫用臺灣神宮（301）的座標與半徑。任務啟用後，在 GPS 選取此目標，使用單次定位或持續追蹤打卡；過往神社集章不算完成，也不因任務打卡新增神社章。完成後臨時目標消失，重新選回自動尋路。重置劇情會清除任務紀錄。

`CHAT_TASK_TEST_MODE = true` 時，選中特殊任務會顯示「作弊打卡」，只完成當前任務。正式版可設為 false 隱藏並停用此入口。舊版十秒倒數已移除。

第二階段使用 `台灣神宮2.csv`。讀完編號 39 的 OS 後，玩家端暱稱改為「加藤」，並隨進度保存；不在 NPC 自我介紹時提前改名。編號 40 的 hint 啟用「加藤口中的其他地方」，座標 25.042754, 121.51503，半徑 50 公尺。此任務與第一階段獨立完成。編號 1 的圖片檔名目前仍是文字訊息，尚未接圖片附件。

第三階段使用 `台灣神宮3.csv`，階段末任務「回憶」座標為 24.93402367031506, 121.37030686705481，半徑 50 公尺。完成後才能讀取第四階段；缺檔仍保留目前進度。

`blank`：訊息 A/B 可留空，「秒數」必填非負數。它是無輸出的等待節點，不產生泡泡、輸入動畫或玩家選項，也不額外加固定 3 秒。只有留在指定聊天室且瀏覽器分頁可見才計時；返回列表、個人頁、關閉聊天室、切到背景或重新整理均重等完整秒數。時間到直接執行下一列，完成後保存進度。第三階段編號 43 設為 7 秒。

第四階段是結局，使用 `台灣神宮4.csv`：

- `think`：A/B 可留空，秒數必填。固定等 3 秒，再顯示指定秒數的輸入動畫，不送訊息。離開仍按時間推進。
- `click_delete`：顯示 A 為選項，點擊後每字 60ms 從末尾刪除，帶游標，不送訊息。已開始後離開，回來自動從完整文字重播刪除，不必再點。
- `type`：每列先停 1 秒，再每字 100ms 自動輸入 A，帶游標，打完送出玩家泡泡。B 有內容時可翻譯。離開未完成會重播本列，已送出不會重複。兩種逐字演出不使用秒數欄，也不能點擊快轉。
- 進入編號 41 的 OS 時，立即移除加藤對話並清空聊天紀錄、返回列表；41 的文字在列表底部呈現。編號 42 在列表底部接續；讀完發放行囊「回憶」，顯示獲得提示。照片區目前空白，附字「你拯救了一個彌留中的靈魂」。
- 結局與物品存在此關卡的存檔中，重整不重複發放；測試用重置會一起清除回憶。編號 41、42 是目前結尾事件的固定編號，調整列號時須同步修改程式。

NPC 段落直接接 `type` 時略過「確認已讀」，自動銜接打字演出；接一般玩家操作時仍保留確認。

測試跳章：解謎的臺灣神宮「重置劇情」按鈕開啟章節選單。「重置／第一章」回到尚未開始解謎；第二至第四章從該章第一列開始，重建所有前章已送出的 NPC／玩家訊息與任務完成紀錄（不加入 OS、blank、think 或刪除的文字）。第三章起暱稱是加藤。每次跳章清除後續進度、聊天室消失狀態及回憶獎勵，不更改一般集章與其他道具。先讀取並驗證所需 CSV，再寫入；缺檔不覆寫。

`CHAT_CHAPTER_TEST_MODE` 控制章節入口與操作，設為 false 即隱藏並停用。這是測試開關，正式的員工身分驗證尚未實作。它與 `CHAT_TASK_TEST_MODE`（作弊打卡）分開控制。

第四章編號 13 的 `click_delete` 特例：點擊後整個網頁黑屏 1 秒，恢復時才開始刪字。使用最上層 modal 覆蓋聊天室及後方介面；其他刪字列不受影響。中途離開後重播黑屏與刪字，重置／登出會清除遮罩。黑屏時長由 `CHAT_DELETE_BLACKOUT_MS` 控制。

第四章讀完 42 即標記「已完成解謎」，入口維持停用。「回憶」物品與獲得提示同步延後 10 秒，等待期間行囊尚無此物品，不要求聊天室保持開啟，在集點卡的任一分頁均可顯示。離開網站／切到背景、重整或返回此頁後重新計時，不保存已等秒數。神社地圖是另一頁，不在那裡顯示此提示。提示文字為「你收到了一個物品，去行囊看看吧。」；照片展示無可見標題。
